# Changelog

## 1.1.1

- Changelog only: no change to the mod.

## 1.1.0

- First release: the explored area of every connected player is added to every map
  table, map tables share with each other, and the area is kept between restarts.
- Settings are in `BepInEx/config/Tie.SharedExploration.cfg`. A `local.sharedexploration.cfg` from
  an earlier build is moved to the new name on the first start, with its settings.
